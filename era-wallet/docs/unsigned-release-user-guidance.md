# ERA Wallet direct-download user guidance

Download ERA Wallet only from <https://www.eraprojects.io/> and verify the published SHA-256 checksum before installation or opening. ERA support will never ask for your recovery phrase, private key, PIN, or password.

## Android

This Android release is distributed directly by ERA Projects and is not yet available through Google Play. Android may display an installation warning because the application is being installed outside Google Play. The APK is signed with the current local ERA Projects release certificate.

## Windows

This Windows release is not yet signed with a publicly trusted Windows code-signing certificate. Windows Defender SmartScreen may display an unknown-publisher warning. Verify the ZIP checksum, extract the complete ZIP, and run `era_wallet.exe` from inside the extracted folder. Do not download or run a standalone EXE.

## Apple platforms

iOS and macOS are not publicly available. Apple Developer organization enrollment, signing, notarization, and App Store publication remain pending.
